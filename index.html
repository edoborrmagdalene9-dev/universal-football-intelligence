What this version can do

• Fetch selected real match/event files from StatsBomb Open Data when online.

• Count events and shots and sum xG when the source provides it.

• Build a transparent independent-Poisson scoreline grid from entered expected-goal rates.

• Parse decimal odds pasted as text and calculate implied probabilities.

• Save a small forecast log in browser storage and export it as CSV.

What it cannot honestly claim

• Universal live coverage or direct SportyBet booking-code decoding.

• Full optical tracking, exact player-body coordinates or all ball trajectories.

• Reliable weak-foot, substitute impact and play-style labels for every player.

• That a 15- or 20-goal scenario cap turns unlikely outcomes into likely real-world outcomes.

• Guaranteed wins. The model needs out-of-sample testing and calibration.

Data source

StatsBomb Open Data repository: github.com/statsbomb/open-data. This site makes browser requests to its public raw files; network access and provider availability are required. No private API key is embedded.
