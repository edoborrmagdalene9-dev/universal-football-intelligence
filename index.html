Scenario assumptions checklist

MARKET MICROSTRUCTURE · 90-MINUTE SURVIVAL GATE

5400 Bookie-Edge Gate

Reject weak, stale, overpriced or poorly supported selections. This is a conservative screening gate, not proof a bookmaker is trapping you or that a surviving selection will win.

CORE RULE

5400 checkpoints ≠ 5400 independent confirmations

EXPERIMENTAL FILTER

5400 seconds represents 90 minutes. The gate uses match time to set the expected number of elapsed checkpoints (60 per minute) and continuously reevaluates fresh inputs when the app receives them. Repeating the same unchanged odds 5400 times does not create evidence. A candidate must pass every hard gate below; otherwise it is discarded or marked insufficient data.

CANDIDATES

Candidate evidence JSON

Use decimal odds and probabilities from 0 to 1. Include a real ISO timestamp, independent out-of-sample sample count, snapshot count and uncertainty estimate. A source timestamp is required; browser capture time is not a substitute for source freshness.

Waiting for candidate data. No selection is approved by default.
SQUAD · REFEREE · MATCH PHASE

Crainee Advanced Match Risk & Chaos Gate

EXPERIMENTAL HEURISTIC

Scores squad market-value/age/caps inputs, average referee whistle gaps and elapsed match time. This is a contextual risk heuristic, not a calibrated match-win probability. Missing player values use the stated defaults and are reported as assumptions.

Waiting for squad and referee data. No match is cleared by default.

The stake output is only a mathematical cap derived from this heuristic, not a recommendation to bet. Do not enter borrowed money or treat this score as proof of an edge.

HOW TO READ THE GATE
  • Net EV: estimated model probability × decimal odds − 1, reduced by an uncertainty haircut.
  • Conservative edge: lower-confidence model probability minus de-vigged market probability.
  • 5400 survival: checkpoints track elapsed match time; a candidate survives only if every hard data/edge rule passes on each fresh evaluation. Past checks cannot guarantee future stability.
  • Discard: stale source timestamp, missing evidence, too few independent validation matches, excessive uncertainty, inadequate conservative edge or negative/insufficient net EV.

Never interpret unavailable markets or sudden odds movement as proof of manipulation. The filter does not place bets and does not promise profit.
